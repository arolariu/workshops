## The JSON event format this lab relies on (Phase 3 spike, Copilot CLI 1.0.99-2; recorded agent-check runs; the SDK schema)

- `copilot -p … -s --output-format json` prints pure JSONL. Events are `{ type, data, id, timestamp, parentId, ephemeral? }`; the last one, `result`, is **flat**: `{ type, timestamp, sessionId, exitCode, usage: { premiumRequests, totalApiDurationMs, sessionDurationMs, codeChanges } }`.
- There is **no** `session.start` and **no** `assistant.usage` event (the old hard fixture used both). Startup is `session.*` events (`session.tools_updated` carries `{ model }`), then `user.message { content }`, then per turn `assistant.turn_start { turnId }` … `assistant.message { content, toolRequests: [{ toolCallId, name, arguments (object) }] }`, `tool.execution_start { toolCallId, toolName, arguments, turnId }`, `tool.execution_complete { toolCallId, turnId, success, result: { content } | error: { message, code } }`, `assistant.turn_end`; then `session.usage_checkpoint`, `assistant.idle`, `result`. Streaming pieces (`assistant.message_delta`, `assistant.tool_call_delta`, `tool.shell_output`, `model.call_*`) are ephemeral.
- Tokens: `session.usage_checkpoint.data.accountingSnapshot.modelMetrics[<model>].usage.{ inputTokens, outputTokens, cacheReadTokens, cacheWriteTokens, reasoningTokens }`; `inputTokens` already includes cache reads and writes.
- A denial is `tool.execution_complete` with `success: false` and `error.code: "denied"`: by a hook (`"Denied by preToolUse hook: …"`) or by the permission system (`"Permission denied because no interactive user response was available. …"`).
- A failed tool is `success: false` with another code. The SDK's `ToolResultType` is `success | failure | timeout | rejected | denied` and the tests assert `error.code` equals it (`github/copilot-sdk`, `java/sdk/src/test/java/com/github/copilot/ToolResultsTest.java`). A session error is `session.error { errorType, errorCode?, message }` (`SessionErrorEvent.java`: `errorType` e.g. `"rate_limit"`, `"quota"`, `"context_limit"`).
- Recorded runs on disk (free to read): `labs/.runs/**/case-1/stdout.txt` (15 JSON runs from the Phase 3/4 agent sweeps) and the Phase 3 spike files in the session folder. Every one of them exits 0 and has no tool failure other than denials.
- `copilot help limits`: `--max-ai-credits` is a **soft cap** (minimum 30): usage is known only after a response, so a response can cross it; then "the next model call is final; tools will be disabled". `copilot --help` (1.0.101-0 on 20 Oct) also lists `--usage-output-file`, `--plan`, `--mode`.
